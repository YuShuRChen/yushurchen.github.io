Projects

  • Win 2026 – Present
    TAGGRAPH: Long-Term Memory for LLM Agents – Graduate Research
    • Designed and led implementation of a graph-based long-term memory system for LLM agents, extracting conversational notes and organizing them through a hierarchical tag ontology for cross-session retrieval.
    • Built resumable ingestion for local and Kubernetes runs, reusing validated outputs and syncing notes and manifests to Hugging Face Hub in the background. Added regression tests for partial uploads, provider outages, and retry limits.
    • Built a shared evaluation pipeline for LongMemEval, LoCoMo, and ATANT, using the same extracted notes in each comparison to isolate the effects of tag matching, candidate filtering, hierarchy expansion, and ranking.
    • Implemented lexical and embedding-based tag matching and MiniLM note ranking with entity/date signals; retrieved all labeled evidence within the top 12 notes for 90.2% of 479 answerable LongMemEval-S questions.
    • Achieved 85.4% answer accuracy on 500 LongMemEval-S questions with GPT-4.1-mini, averaging 6.9K input tokens per question, compared with 66–89% at 4–7K input tokens for three systems evaluated by OmniMemEval.
  • Spr 2026 – Present
    Neural-Operator-Guided Motion Planning – Machine Learning for Physical Applications
    • Designed a hierarchical planner for dynamic navigation, combining global route guidance with sliding-window local replanning to respond to moving obstacles while limiting A* search cost.
    • Co-developed a PyTorch planning pipeline that used a neural operator to predict cost-to-go fields from maps, goals, and directional obstacle risk, then fed those estimates into A* to guide route search.
    • Reduced mean A* node expansions during replanning by 98.6% (3.62M to 51.7K) with sliding-window search versus whole-map search, using the same neural operator in matched 256×256 simulations.
    • Training neural operators in PyTorch and comparing curriculum learning strategies by measuring how accurately the resulting models predict cost-to-go fields on planning maps held out from training.
